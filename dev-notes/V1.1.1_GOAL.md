> **Per the dsh-production-agentic-engineering skill**, this is
> the deterministic execution contract for v1.1.1 — the
> patch release that ships the bulk error-audit pass and the
> Playground UI (deferred from v1.1.0).
>
> Two parallel tracks:
> 1. **Bulk audit** (this repo, `loopy-agent`) — finish the
>    error-message audit pass rate from ~27% to >= 95%
> 2. **Playground UI** (separate repo, `loopy-playground`) — the
>    Next.js + shadcn + Pyodide web app

## Phase A — Bulk error audit (loopy-agent)

### A.1 — Catalogue the remaining sites

The v1.1.0 audit (`scripts/audit_errors.py`) already writes
`dev-notes/ERROR_AUDIT.json` with every `raise` site flagged
`passes` / `needs_work`. The current baseline is ~27% (after
the 12 hand-pinned exceptions ship). v1.1.1 takes this to
>= 95%.

### A.2 — Patch every needs_work site

- **Rule**: every `raise ValueError(...)` or
  `raise SomeError(...)` in `loopy/` ends with a docs URL
  matching `https://loopy.dev/docs/...#anchor`.
- **Approach**: hand-patch the remaining ~60 sites one file
  at a time, verifying after each batch.
- **Tooling**: keep `scripts/audit_errors.py` as the
  authoritative pass-rate check. Run it after every batch.

### A.3 — Loosen the xfail, un-xfail the audit test

- `tests/test_error_messages.py::TestErrorAuditThreshold::test_audit_at_least_95_percent_pass_rate`
  is currently `xfail(reason="v1.1.1")`. Once the audit passes,
  remove the `xfail` marker and re-verify.

### A.4 — Commit + release

- Branch: `fix/v1.1.1-bulk-audit`
- Version bump: 1.1.0 -> 1.1.1
- Tag: `v1.1.1`
- Push: `git push origin master --tags`

## Phase B — Playground UI (separate repo)

### B.1 — Scaffold the repo

- `loopy-playground/` (NEW repo, sibling to `loopy-agent`)
- Next.js + TypeScript + Tailwind + shadcn
- Branch: `main` (initial scaffold)

### B.2 — Marketing site (Layer 1)

- `/` — hero, feature cards, "Try Playground" CTA
- `/playground` — the tabbed workspace

### B.3 — Workspace (Layer 2)

- 5 tabs, one per major surface:
  1. **Agentic Loop** — minimal AgentLoop with TestModel
  2. **Verified Agent** — VerifiedAgent + invariants
  3. **Durable Workflow** — DAG + Saga + journal
  4. **Federation** — FederatedServer endpoints
  5. **Compliance + Cost** — PolicyEngine + max_cost_usd
- All execution client-side via Pyodide
- All code stored in `localStorage` only

### B.4 — Export surface (Layer 3)

- "Copy to clipboard" — a single `main.py` file
- "Open in Replit" / "Open in GitHub Codespaces" buttons

### B.5 — Deploy

- Vercel or GitHub Pages (free static)
- Pyodide runtime vendored (~25 MB)
- `playground.dream-pixels-forge.dev`
