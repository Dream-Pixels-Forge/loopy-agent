## Phase A — Service-mode FederatedServer (T2.1)

### A.1 — `python -m loopy serve --workers N`

- Public surface: `FederatedServer(workers=N, host=..., port=...)`
- Adds a real worker pool via `multiprocessing` or `asyncio`
  tasks (no `multiprocessing` — keep stdlib + httpx only)
- Real `/tasks` POST becomes an async queue
- `GET /tasks/{id}` polls the in-process worker
- `GET /tasks/{id}/stream` becomes an SSE event stream
- `POST /tasks/{id}/cancel` is a soft-cancel
- **`python -m loopy serve --port 8080 --host 0.0.0.0`**
  is the canonical invocation

## Phase B — Multi-tenant gateway (T2.2)

### B.1 — `Gateway(tenant="acme", cost_tracker=...)`

- New kwargs on `Gateway.__init__`:
  - `tenant: str | None = None` — partition cost + audit log
  - `cost_tracker: CostTracker | None = None` — per-tenant caps
  - `policy_engine: PolicyEngine | None = None` — per-tenant
- New `CostTracker.tenant_totals(tenant_id)` returns
  `{"used": int, "limit": int, "remaining": int}`
- New `PolicyEngine(per_tenant=True)` reads policies from
  `./loopy.policies.d/{tenant_id}.yaml`
- All new kwargs are optional — single-tenant use is unchanged
- **`Gateway(tenant="acme")`** is the canonical invocation

## Phase C — Adaptive retry + circuit breaker (T2.3)

### C.1 — `Policy.exponential(max_attempts=5, base=1.0, cap=30.0)`

- New factory function in `loopy/policies.py`:
  - `Policy.exponential(max_attempts, base, cap, jitter=True)`
- Reuses `tenacity` (already in `[gateway]` extra)
- Default `jitter=True` uses full jitter (exponential random)
- Exposed on `Gateway.retry_policy` for outbound HTTP calls
- Visible in `Gateway._call_*` (per `AUDIT.md` AUD-R01)
- **`Policy.exponential(max_attempts=5)`** is the canonical
  default for v1.2

## Phase D — Hot-reload + Dev server (T2.4)

### D.1 — `python -m loopy dev`

- New CLI subcommand `loopy dev <script.py>`
- Watches the script (and its imports) for changes via
  `watchfiles` (add to `[dev]` extra) and re-runs on save
- Integrates with the playground: live errors stream to
  the workspace via WebSocket
- Includes a `loopy doctor` subcommand that diagnoses
  common config issues (missing API key, wrong Python
  version, broken venv)

## Phase E — Language server (T2.5)

### E.1 — `pip install loopy-agent[language-server]`

- New optional extra `language-server` in `pyproject.toml`:
  - `pygls>=1.0` (Python Language Server)
  - `lsprotocol>=2023.0`
- New `loopy.lsp` module with:
  - Autocomplete for `PolicyEngine`, `Condition`, `Invariant`
